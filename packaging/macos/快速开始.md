# OKX 工作台 macOS 交付说明

应用源码基线：`0dae104cf4799344a26902233b3fb1ef14aab327`。个人使用版桌面包装版本 `0.1.0-macos.2`，准确打包提交与 SHA256 见同目录 RELEASE.json / SHA256SUMS.txt。

## DMG 安装与启动

1. 本包面向 Apple Silicon（arm64，M 系列）Mac，最低声明 macOS 26.5，实测 macOS 26.5.1。未验证更低系统或 Intel，不提供 Intel / universal2 兼容承诺。
2. 核对 SHA256：在下载目录运行 `shasum -a 256 -c SHA256SUMS.txt`（校验文件列出的 DMG、源码 ZIP 和 RELEASE.json 须放在同一目录）。
3. 双击 DMG，将 **OKX Workbench.app** 拖到 **Applications**。弹出磁盘映像后，从“应用程序”双击启动。允许安装目录包含空格。
4. 应用自动打开本机浏览器，原生窗口可选择“离线演练 / OKX 模拟盘”，并提供“配置模拟盘”“打开工作台”和“暂停并退出”。关闭小窗口或使用 ⌘Q 也会暂停策略并退出本机服务；只关闭浏览器标签不会退出服务。

DMG 内的 `.app` **内置 Python 3.14.3 和锁定依赖**，无需另装 Python、uv、Homebrew、Node 或 Xcode；启动及离线演练无需联网。它是 macOS 独立应用交付，不是仅装入磁盘映像的源码 ZIP。独立源码 ZIP 为补充材料，源码安装方式需要运行环境与首次下载依赖。

**个人使用版保留 ad-hoc 签名，不安排 Developer ID 或公证。** 签名完整性检查通过，但 Gatekeeper 的 `spctl --assess --type execute` 实测返回 **rejected**；这与签名文件未损坏是不同检查。下载后可能出现无法验证开发者提示，本地无下载隔离属性的启动通过不代表其他机器自动通过。

如你确认来源和 SHA256 无误，首次尝试打开后，可按 macOS 提供的逐应用确认操作：打开“系统设置 → 隐私与安全性”，找到被阻止的 OKX Workbench，选择“仍要打开”（Open Anyway），再完成系统确认。此操作必须由使用者自行决定，不是全局关闭 Gatekeeper；本次未代用户执行。若没有该选项、设备策略禁止或提示恶意软件/文件损坏，停止并反馈，不使用终端移除隔离属性或降低全局安全设置。系统入口依据：[Apple 官方打开应用说明](https://support.apple.com/en-us/102445)。

## 默认行为与用户数据

- **始终 demo 模拟环境，实盘禁用。** 首次默认无密钥离线演练；原生窗口显式选择 OKX 模拟盘后才允许后端连接模拟 API。没有实盘入口或 live 参数。桌面版默认单笔/总名义上限各 25 USDT，页面显示当前服务端限额。
- 忽略继承的 OKX/数据库/风控变量及任意 `.env`。点击原生“配置模拟盘”先暂停并停服，三个输入均为安全输入框，保存到用户目录的 `demo-credentials.json`（当前用户所有、0600、父目录0700），不回显至网页或日志、不内置包中；选择在线时才由后端读取这个明确的模拟盘配置。配置须来自模拟盘，不能填写实盘凭据。
- 账本、审计、原生配置、无密钥配置样例、退出控制状态及日志写入 `~/Library/Application Support/OKXWorkbench/`，不写入只读 DMG 或应用包。数据属于本机用户，不随退出清除。
- 监听随机本机端口 `127.0.0.1`，地址显示在原生窗口。一个账本只允许一个实例。源码入口使用同一用户数据目录与锁，不能与桌面版并行占用。
- 配置/来源切换先退出旧服务再重启，保持同一账本、账户绑定与锁；策略暂停，不自动平仓或撤单。单向模式及读取+交易、无提现权限确认通过后，网页 START_DEMO 确认才允许启动；认证/权限失败继续暂停。网页不提供凭据读写接口。
- “暂停全部策略”仅停后续信号，不自动平仓/撤销；账本及交易所持仓均须按各自口径管理。退出再启动始终暂停，需重新确认启动。

## 无密钥验收步骤

1. 页面应显示“离线演练”和模拟环境，账户初始资金来自本地账本，不是真实交易所余额。
2. 选择 BTC 或 ETH、1H/4H/1D，点击自动生成，检查训练/后 30% 样本外结果；此时策略不应自动运行。
3. 点击全样本回测，查看净收益、回撤、权益曲线和 CSV。改合约/均线后应提示“上次结果”，CSV 仍对应旧快照；重跑后更新。
4. 检查信号预览并确认离线启动，执行一次信号，查看本地执行记录。信号不是每次都开仓：hold、duplicate、expired 都应如实显示。只有收盘后最长 300 秒内的信号可执行，过期等待下一根；不能把离线订单叫作模拟盘真实成交。
5. 暂停后执行应被拒绝；关闭应用再启动仍为暂停。最后用原生窗口“暂停并退出”结束服务。

**验收范围：** 审查基线的离线/mock 信号流程、104 项 pytest、30 项独立桌面/手机检查及 CI 已通过。早期版本完成过真实 OKX 模拟盘信号触发、开仓成交及平仓；**当前 `0dae104` 和本桌面包装未重新做真实 OKX 模拟盘联调**，不能表述为最新真实模拟盘验收全部通过。本次打包验证仅离线，不访问 OKX 或发起交易。

本轮真实模拟盘续验因指定仓库外模拟盘凭据文件缺失而停止，尚未认证或下单，最新结论见 `docs/DEMO_REVALIDATION.md`。恢复联调需提供独占权限 JSON 中的 `api_key`、`secret_key`、`passphrase`，仅读取+交易、无提现，并满足账户 IP 白名单；不要在评论中粘贴密钥。桌面 `.app` 已增加模拟盘入口，但当前只有离线/mock 验证，尚无最终包的真实模拟成交证据。源码脚本的联调记录与打包应用必须分别验收，不能混称。

包内提供开发自检 `OKXServer --self-check-offline`：使用明确的模拟时钟和合成历史 K 线，走包内原始 Engine/API 链路，断言新鲜做多信号实际 filled、重复执行 duplicate 且订单恰好一笔。自检临时账本随结束清理，不读取凭据、不连接 OKX，不把该结果当作真实模拟盘成交。

## 源码运行与重新构建

源码 ZIP 含完整源码、测试、`uv.lock`、无密钥 `.env.example` 及本说明；不含凭据、真实 `.env`、用户账本、订单、缓存、.venv、编译产物或 Git 历史。解压到任意干净可写目录（可含空格），安装 uv（已验证 0.11.6）后，双击 `安装源码依赖.command`，再双击 `启动源码离线演练.command`；首次需联网下载 Python 3.14.3 与锁定依赖。终端显示本机地址，Ctrl+C 停止。源码包本身不是独立可执行程序。

开发者重新构建需相同架构 macOS、Xcode 命令行工具、Python 3.14.3：创建隔离环境，安装 `packaging/macos/build-requirements.txt`，再以 `--require-hashes` 安装 `runtime-requirements.txt`，运行 `packaging/macos/build_release.py`。应用业务源码必须与审查基线一致，构建器会拒绝差异。PyInstaller 依据：[官方构建与签名说明](https://pyinstaller.org/en/stable/feature-notes.html)。

## 剩余限制

账户协调仅限同机同用户持久目录；实盘持续禁用。未知订单无法确认终态时持续阻断；旧 Key 撤销且记录归属不可核实时拒绝迁移。回测未建模执行延迟、资金费、清算、深度和张数取整，收益不能推断真实表现。已知非阻塞项包括旧订单迁移成交数量核对、只读对账循环的数据库异常恢复及收益附加接口失败隔离。桌面包装新增双来源、本机受限配置与生命周期控制，尚待独立增量审查；当前真实模拟盘凭据缺失是联调阻塞。
