# 源码版中文快速开始

需要macOS或Linux、Python 3.11+及uv。在源码目录运行：

```bash
uv sync --frozen --group dev
cp .env.example .env
chmod 600 .env
uv run uvicorn okx_workbench.app:app --host 127.0.0.1 --port 8000
```

首次安装依赖需要联网。配置样例默认模拟环境、离线合成行情，无需密钥；实盘始终禁用。只启动一个进程，浏览器打开 http://127.0.0.1:8000 ，退出用终端Ctrl+C。

1. 确认页面显示“离线演练”，选择BTC或ETH。在“K线周期”选择1m（每分钟）、1H（每小时，默认）、4H或1D。
2. 点击“自动生成策略”。行情、保存的策略和样本外结果应使用所选周期；生成后保持暂停，不下单。生成器会选择均线参数，页面显示返回的实际参数。
3. 点击全样本回测，检查结果快照中的合约、1m周期、均线、费用和数据源，再导出CSV。改变周期或参数后显示“上次结果”，旧收益与CSV仍对应旧快照；重新回测才更新。
4. 如需离线执行，检查保存的策略参数与信号预览后确认启动。1m与其他周期共用原始收盘时间和最长300秒期限：恰好300秒仍有效，超过即等待下一根已确认K线；预检或提交准备跨过期限也不得下单。不保证每次都出现开仓信号。
5. 点击“暂停全部策略”；生成与回测不会自行启动，重启服务也保持暂停。暂停不自动平仓或撤销已有挂单。离线订单来自本地账本，不能当作交易所成交。

接入模拟盘前按 [README](../README.md#连接-okx-模拟盘) 在本机配置模拟盘身份、读取+交易且无提现权限、单向模式及独立测试账户。不得在评论、报告或Git中发送凭据。此前联调用Key已出现在评论，**轮换/撤销与本机配置更新仍待用户完成，开发不再使用旧Key交易**；未确认轮换，不宣称已完成。不要删除现有账本或账户绑定以绕过去重/未知订单阻断。
