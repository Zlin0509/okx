# PR #1 审查问题修复

基于 `14ff014cb88290974eb95067cf5a974eb614fe6e`，处理测试审查 `01a1d0ab-8f12-7424-a878-ecad79afe578` 和界面审查 `01a1d2c3-cc6b-7cd7-970f-d5980dcd45c5`。验证全部使用临时 SQLite、FakeOKX / HTTP MockTransport、静态页面和浏览器 route mock；未读取交易凭据、访问 OKX 或发起新交易。

| 审查项 | 修复与回归依据 |
| --- | --- |
| 测试 P1：异常订单永久阻断 | 先独立提交 submit_started，再 POST；崩溃前确定未提交的新版意图和离线遗留意图安全取消。旧版/未知意图逐笔查单并保留错误码，连续三次明确查无后允许带依据人工解除，重新核对无挂单/目标持仓；原信号永久去重。回归覆盖两处崩溃、网络/权限错误、已有订单/仓位/挂单、超过 100 条历史、HTTP 审计和启动对账。 |
| 测试 P1：跨数据库/Key 互斥 | 以认证 UID 代替 Key 指纹，单机共享目录将 UID 原子绑定唯一数据库；多 Key 双数据库并发仅一方能执行，同数据库换 Key 保留去重。旧版迁移留审计和时间截止，未核对的其他旧 Key 记录阻断执行。跨主机/用户/独立容器不受保证，因此本版无条件拒绝实盘启动，即使 ACK 完整。 |
| 测试 P2：回测预算和成本 | 执行、训练、样本外和完整回测共用 opening_budget，默认初始名义预算由 500 修正为 100 USDT。回测滑点默认 20 bps，可单独改场景；界面固定显示有效预算、成本假设和实时盘口 IOC 偏移，两者不冒充实际相对信号价成本。回归对比首笔预算，张数取整差小于一个 lot 的名义值。 |
| 测试 P2：信号时效 | 所有周期默认/最大 300 秒执行窗；过期/超前信号不补单，策略等待新 K 线。启动预览和执行返回年龄，上次检查记录可见。1H/4H/1D 在 0、300、301 秒、23 小时和超前时间逐项回归。 |
| UI P1：暂停后迟到启动 | 持久化 control_epoch 在暂停时递增，启动预检结束后原子校验，排队的旧 HTTP 启动同样拒绝。可控 Event 阻塞预检，暂停返回后释放，active 始终为 false，后台 tick 不提交。前端取消在途启动时发送暂停，并忽略失效响应；桌面/手机模拟迟到成功也未追加 tick。 |
| UI P1：断连和暂停刷新失败 | 所有尺寸持续显示连接状态和最后同步时间；失败显示待同步、清空金额、禁用启动/执行、保留暂停入口。暂停确认与刷新失败分开反馈；旧刷新/账户响应不能覆盖新状态。浏览器覆盖运行中断连、toast 消失、恢复连接、暂停成功后刷新失败。 |
| UI P2：阻断订单不可见 | 总览持续列出全部阻断订单、中文状态、错误和恢复条件，不受普通事件覆盖；启动禁用，手机将状态置于记录首行。提供人工解除对话框，记录身份标签/依据/确认短语；没有重发按钮。 |
| UI P2：回测结果冒充新参数 | 固定结果的参数、源、时间和数据区间，任一输入变更立即标记上次结果；CSV 按结果 ID 导出并包含参数元数据。浏览器验证 BTC/MA8/24 → ETH/MA20/80，旧结果保持 BTC，重跑后快照与 CSV ID 更新；后端验证旧 CSV 内容不变。 |

额外修复：撤单逐笔 sCode 校验；单笔查单失败隔离；启动仅对账不激活；CI 增加 JavaScript 语法检查。

验证：`uv run pytest -q`（74 项通过）、`uv run ruff check .`、`uv run ruff format --check .`、`node --check okx_workbench/static/app.js`。浏览器脚本 `tests/browser_regressions.js` 在 1440×1000、390×844 两个尺寸共通过 10 个场景断言，迟到启动后的 tick 数为 0，无整页横向溢出。脚本通过 Playwright `browser_run_code` 加载；静态服务器命令：`python3 -m http.server 8766 --bind 127.0.0.1 --directory okx_workbench`。所有 API 都被 route mock 接管。

边界：主机协调是持久绑定，不是分布式锁；不同主机/OS 用户/独立目录与人工交易不受保证，实盘关闭。手工解除依赖操作人的真实核对，查无不构成未提交的证明；不确定时继续停单。回测仍不包含执行延迟、资金费、清算和深度，数量尚未按交易所 lot 取整。收益附加接口仍可能因上游读取失败整体不可用（P3），界面显示不可用。原始 37 项验证和此前模拟成交是历史证据，本轮没有重复交易；最终验收仍需独立测试与界面复审。
