| 测试 P1：异常订单永久阻断 | 先独立提交 submit_started，再 POST；崩溃前确定未提交的新版意图和离线遗留意图安全取消。旧版/未知意图逐笔查单并保留错误码，禁止人工作废；暂停后继续只读对账至交易所可确认终态，原信号永久去重。覆盖两处崩溃、延迟可见后成交、任意查无次数/空快照、两种 HTTP 查无形态、旧版 abandoned 恢复、超过 100 条历史、HTTP 审计和启动对账。 |
| 测试 P1：跨数据库/Key 互斥 | 以认证 UID 代替 Key 指纹，单机共享目录将 UID 原子绑定唯一数据库；多 Key 双数据库并发仅一方能执行，同数据库换 Key 保留去重。旧 Key 撤销时，通过新认证账户查单并核对身份后迁移（含终态）；留原审计和时间截止，查无/不匹配阻断。事务失败回滚数据及本次新绑定，已有绑定不删除，崩溃保留绑定。跨主机/用户/独立容器不受保证，因此本版无条件拒绝实盘启动，即使 ACK 完整。 |
| 测试 P2：回测预算和成本 | 执行、训练、样本外和完整回测共用 opening_budget，默认初始名义预算由 500 修正为 100 USDT。回测滑点默认 20 bps，可单独改场景；界面固定显示有效预算、成本假设和实时盘口 IOC 偏移，两者不冒充实际相对信号价成本。回归对比首笔预算，张数取整差小于一个 lot 的名义值。 |
| 测试 P2：信号时效 | 所有周期默认/最大 300 秒执行窗；过期/超前信号不补单，策略等待新 K 线。启动预览和执行返回年龄，上次检查记录可见。1H/4H/1D 在 0、300、301 秒、23 小时和超前时间逐项回归。以原 deadline 在预检后、提交标记前和 POST 紧前复检；账户预检及两次事务跨窗、构造请求前跨窗均断言零 POST。 |
| UI P1：暂停后迟到启动 | 持久化 control_epoch 在暂停时递增，启动预检结束后原子校验，排队的旧 HTTP 启动同样拒绝。可控 Event 阻塞预检，暂停返回后释放，active 始终为 false，后台 tick 不提交。前端取消在途启动时发送暂停，并忽略失效响应；桌面/手机模拟迟到成功也未追加 tick。 |
| UI P1：断连和暂停刷新失败 | 所有尺寸持续显示连接状态和最后同步时间；失败显示待同步、清空金额、禁用启动/执行、保留暂停入口。暂停确认与刷新失败分开反馈；旧刷新/账户响应不能覆盖新状态。浏览器覆盖运行中断连、toast 消失、恢复连接、暂停成功后刷新失败。 |
| UI P2：阻断订单不可见 | 总览持续列出全部阻断订单、中文状态、错误和恢复条件，不受普通事件覆盖；启动禁用，手机将状态置于记录首行。明确提示持续对账及禁止人工作废；已移除解除表单，任意次数查无均不提供解除入口。 |
| UI P2：回测结果冒充新参数 | 固定结果的参数、源、时间和数据区间，任一输入变更立即标记上次结果；CSV 按结果 ID 导出并包含参数元数据。浏览器验证 BTC/MA8/24 → ETH/MA20/80，旧结果保持 BTC，重跑后快照与 CSV ID 更新；后端验证旧 CSV 内容不变。 |

额外修复：撤单逐笔 sCode 校验；单笔查单失败隔离；启动仅对账不激活；CI 增加 JavaScript 语法检查。

验证：`uv run pytest -q`（104 项通过）、`uv run ruff check .`、`uv run ruff format --check .`、`node --check okx_workbench/static/app.js`。增量浏览器脚本 `tests/browser_regressions.js` 还覆盖查无 100 次也不出现解除入口；在 1440×1000、390×844 两个尺寸共通过 10 个场景断言，迟到启动后的 tick 数为 0，无整页横向溢出。脚本通过 Playwright `browser_run_code` 加载；静态服务器命令：`python3 -m http.server 8766 --bind 127.0.0.1 --directory okx_workbench`。所有 API 都被 route mock 接管。

边界：主机协调是持久绑定，不是分布式锁；不同主机/OS 用户/独立目录与人工交易不受保证，实盘关闭。未知订单不能人工解除；交易所永不返回可确认终态时会持续阻断。旧 Key 撤销且历史超出保留期或本地未提交意图无法远端验证归属时，仍需恢复原 Key，不能推测归属迁移。回测仍不包含执行延迟、资金费、清算和深度，数量尚未按交易所 lot 取整。收益附加接口仍可能因上游读取失败整体不可用（P3），界面显示不可用。原始 37 项验证和此前模拟成交是历史证据，本轮没有重复交易；最终验收仍需独立测试与界面复审。
