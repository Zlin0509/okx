# WS 研究数据适配与确定性回放规格

受控基线 346af83／仅代码 f65d9bb。仅导入本 issue 已核验的生产公共 WS 120 秒 ZIP；外部完整 ZIP 与 raw SHA-256 作信任锚，复用日常开发独立只读校验器作导入前检查，不运行原会写派生产物的校验器。原包／旧脚本保留；不采样、不使用评论凭据、不读 M1、不接账户／交易接口，不改现有服务或已通过的费用／统计阶段。

## 固定口径

- 原始记录保存 source、receive_utc、receive_unix_ns 和服务端原文；规范化每条数据保留 exchange ts、各资金费字段、原始行／行内索引。接收纳秒决定回放可得时点；若接收钟倒退则显式诊断、保守使用截至该行的接收高水位释放，绝不重排原始线序使后来消息提前。毫秒研究接口向上取整可得时点，原始纳秒不覆盖。
- UTC 整秒网格只做诊断对齐（1 秒）；价格时效上限 2 秒，资金费状态快照诊断上限 120 秒，均同时检查交易所更新时间及接收时间。阈值是数据质量规则，不根据收益选参。保留完整、重复、同 ts 修订及乱序记录；状态不被较旧交易所时间覆盖，同交易所 ts 使用后收到者。没有序列号不能宣称流无缺包。
- ticker last 和 mark-price 分开；markPx 可适配既有只读 Observed 研究接口，但时标明确为接收时点 as-of 网格，不是日线／共同交易所成交时点。所有组件保留各自 exchange／receive／available。没有可执行成交价、账户权益或下单信息；不编造 DecisionSnapshot 账户字段。
- 断连／重连清除旧状态，禁止跨连接沿用旧报价；输出观察到的断连区间、每流最大间隔、重复、交易所乱序、接收钟倒退、未来时钟／时效及跨币 mark 时间偏差。28 个币对和 8 币篮子的覆盖诊断不是相关性／协整检验，也不授予资格。
- 资金费一律为状态快照，保留 settState、settFundingRate、fundingRate、各结算时间及状态变化；不推导账户现金流，现金流值为 null。即便合成测试出现 processing→settled 也不自动生成账本资金费。真实样本未跨结算点不能当作新结算。
- 没有完整 UTC 日线历史，日线 Observed 集合为空；56／512 日窗口、180 日上市准入、历史币池／资格均未满足或未知。研究桥接明确拒绝模型许可，不执行真实统计筛选、信号或收益回测，不把 120 秒网格充当日样本。普通会员费用模块和参数保留，仅作为未来获准完整回测的既有模块。

## 验证与交付

单测只用合成／mock：时点截断、未来扰动不影响过去快照、公开只读视图、跨币缺项／过时、重复／同 ts 修订／乱序、断连重连、接收钟倒退、资金费转换不记现金、历史／资格拒绝。导入前复用校验器覆盖篡改／缺项／外部锚错误及输入前后哈希不变；额外未列文件按校验器明确策略报告。仅集成读取已核验附件；不运行任何采集脚本。

新版本源冻结、机器结果 manifest、中文覆盖／回放报告、两次离线回放一致及跨版本实际证据独立保存，拒绝覆盖输出目录。真实原包／规范化／对齐输出／集成审计仅进受控数据历史或附件，绝不进仅代码 Git 历史；仅代码保留代码、合成测试与来源／哈希元数据。最终核对全部待交付对象和受控 blob 交集；不推送、不新增唤醒。并发 P1、已知非阻断 vector P2、真实历史／样本外／发布共享门槛继续保留。
