# M3 实现记录与边界

定义／数值／测试规格先在 622957e 提交，随后实现；未读取真实市场窗口。所有样例都是固定种子 290411 的人工数据，SYNTHETIC 标记不是统计认证。

首次状态机验证中，关系突变样例退出后仍可能凭旧测试许可再次开仓。因此增加 relationship_invalidated 锁定，关系失效后本次运行永不复用旧许可；这是状态机完整性修复，没有根据收益调整阈值。hard_drift 的风险退出由账本 risk_halt／risk_fill 表达，不伪造信号层退出或统计失效结论。

OLS 的系数是 log 残差导数交易向量，不承诺美元中性；净敞口允许非零并逐笔披露。hedge_error 为实际各腿名义金额到冻结向量最小二乘投影的 L1 相对距离，单腿／零仓视为失败，不是市场 beta。市场 beta 明确 null。周度只约束新开仓；日度关系／执行／超时检查随时发退出。实际账本仍可因价格跳空拒绝某腿，下一次日度检查退出，不宣称原子成交。

描述性 AR(1) 半衰期不授予统计资格；Holm 仅计算外部完整预注册检验族的调整值，不生成 p 值、不连接自动许可。本阶段并未实现正式协整／单位根／关系稳定性检验或相对收益残差，不可把合成 oracle 许可用于实际币种。时间戳为抽象 UTC 日，训练样例不等于 2021–2024 数据。

逐腿 funding_calendar 为明确的合成每日时点，非交易所真实结算周期；正负资金费／费用沿用 R2。开盘价为前一日合成收盘价，合成滑点固定 5bps，不能用于流动性或容量推断。无保证金阶梯、强平、交易所撮合、合约张数／最小量约束或实际深度模拟。

受控 M2 冻结验证不变；M3 新文件具有独立冻结，不向旧 M2 冻结补写新源。真实动作入口在任何文件读取前拒绝，代码与市场数据无导入依赖。旧报告与独立日志的勘误索引见 M3_DESIGN.md，旧证据保持原字节。

窗口末端没有后续成交时，记录 unexecutable_signal／unresolved_signal_ids，保留实际仓位并按右删失计持仓期，不虚构平仓。CLI verify 会对冻结的合成结果摘要逐字节比较；write 仅用于首次捕获，既有目录拒绝覆盖。CLI 另写本地追加日志，范围仅 CLI，不声称涵盖程序调用／pytest 或与 M2 独立日志串成同链。

首版 f42c012 在 Python 3.12／3.14 的字节结果一致，但 3.11 因内置 sum 的浮点舍入实现不同而拒绝黄金哈希。保留 M3_SOURCE_FREEZE.json、M3_EXPECTED.json、results/m3 和原 CLI 失败日志；V2 对浮点统计显式使用 math.fsum（Decimal 账本求和不变），另写 M3_SOURCE_FREEZE_V2.json／M3_EXPECTED_V2.json／results/m3_v2。没有覆盖首版或调整数值参数；首版源可由 f42c012 恢复。V2 是跨 Python 确定性整改，不涉及真实窗口或收益选择。
