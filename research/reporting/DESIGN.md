# ZLIN-11 冻结账本报告

报告只接收已审查的 R2 六配置 JSON 和 R3 验收 JSON。输入哈希来自 `INPUT_ANCHORS.json`，对应发布候选 `1acd6b7` 和 issue 附件 `ZLIN-11-R3-DELIVERY.json`。原 R3 的发布分支、110 项源冻结、策略、统计与线上应用入口保持原版本。

从已交付的 `ZLIN-11-R3-EVIDENCE.zip` 解出 `synthetic-wiring/` 与 `synthetic-acceptance/acceptance.json` 到本地 `reviewed/`。使用此前锁定的统计环境。该环境仅用于调用冻结的合成价格生成器以恢复标记价和收盘面板，命令无需运行回测、联网或访问市场数据。

```bash
python -m research.reporting --r2-reviewed reviewed/synthetic-wiring --r3-reviewed reviewed/synthetic-acceptance/acceptance.json --output research/runtime/report
```

`REPORT.zh.md` 可引用同目录的三张独立 SVG。所有图从 `results.json` 渲染，图元保存机器结果字段和绘图数据，`MANIFEST.json` 记录五个产物的字节数和 SHA-256。输出目录须是新目录。缺少输入参数、文件、哈希或资格证明时，报告逐项给出不可用原因及空值。任何非合成来源不进入指标层。当前进程审计守卫覆盖 Python 的连接、DNS 和已知受控目录访问，边界沿用 R3。

R2 的事件账本包含一个额外终端开盘。日统计和敏感性只用 47 个完整 UTC 日收盘。终端开盘单列，事件回撤和换手包含该开盘的实际事件。月收益按完整自然月起止权益比计算，边界不完整月份单列。零收益的完整月计入月胜率分母。对齐的 Pearson 使用相邻 UTC 日收盘简单收益，双方舍弃首日，零方差返回空值。对比的日期和资本必须完全一致。R3 策略及两条现货基准使用冻结的独立合成日历，严禁按 R2 账本另行拼接。R3 的策略换手采用冻结的成交名义额摘要，现货换手可逐笔复核。

归因用逐事件上一仓位乘标记价变化，加当笔成交量乘（标记价减参考价），再加成交量乘（参考价减执行价），最后计手续费和资金费。每事件校验实际头寸、非净额资产及关系簿敞口、权益变动；峰谷与全窗同时核对。最大回撤沿事件顺序计量，起点为峰值后第一事件，终点包含谷值事件。相同最大回撤保留首个达到事件。展示的滑点已体现在成交造成的权益变动中。集中度同时披露事件峰值及持仓日收盘平均 HHI，对零敞口不定义 HHI。

结果仅表示合成工程诊断。六配置敏感性使用相同日期和资本，未引入新的配置或选参。R3 输出缺乏完整逐事件账本和单币收盘面板，相关性、集中度与回撤归因返回不可用。真实统计、合格样本外日期与实际资金费结算证明仍待独立核验。
