# M3 R2 整改规格（先冻结）

基线：受控 5bf6adc／仅代码 1e9681d。仅合成／mock，不运行 verify_m2、不打开或枚举 M1 快照；先审读测试与 fixture，再以本地读取防护执行适用回归。旧版本、冻结、结果与越界记录保留。

P1：决策 callback 改成唯一参数 DecisionSnapshot。只含当前时间／估值价、已发生仓位／成交、已知待单摘要、当时 ts<=now 且 available_at<=now 的 observation 副本。无引擎、market、provider、完整 future observations 或绑定引擎方法。嵌套数据用 frozen slots dataclass、tuple、独立 mappingproxy 副本；策略构造函数不接收 observation 数据源，驱动器负责逐时放行。输出 Decision(signals, cancel_books)，策略不能修改引擎以取消待单。公开接口未来键读取失败，枚举仅见已可得前缀，嵌套／属性写入失败；已捕获快照不随驱动推进更新。这是公开接口的结构隔离，不是 Python 同进程安全沙箱。

P2：零名义不参与逐币除法，空／全零分配返回空和 0；零 beta 篮子有效。Holm alpha 显式冻结 0.05（外部 p 值调整只控制 FWER，不声称完成 FDR 或资格接线）。summary 补全正式协整、ADF／单位根／平稳性、稳定性、相对收益残差、真实候选资格、检验族及调整至资格接线的待接项目。

风险预算数值不变：目标毛 .80／单币 .24，实际新开／增加风险成交仍受权益 1／单币 .25 硬门禁。价格／资金费漂移导致的实际超限仍是超限；风险平仓不得加仓、不得翻向，仅减少现有腿，顺序平仓间其他腿可能仍超限。新增独立逐事件风险轨迹与超限 episode（开始／恢复 ts、seq、持续 ms、同一时间戳内事件跨度、峰值、删失）；不把减仓中超限写成合规，不放宽预算或虚构即时成交。时间是合成网格，不作真实处置延迟保证。

CI 移除真实缓存审计入口，加入受保护的合成 pytest 与 m3 verify；仅代码 README 首条命令改为 M3。旧黄金 manifest 与原始市场数据不同：黄金仅是合成生成器输出的内容哈希和长度，可能与受控树中的合成 manifest 共享 blob；私有原始数据／真实结果／受控审计 blob 的隔离另行核验。

新增测试规格：主动访问未来 key／完整引擎属性、枚举未来、篡改 view 各层均失败；available_at 延迟发布和捕获快照不增长；策略不保存数据源；未来扰动不改过去完整账本与信号；零 beta／空分配；新开限额与每个风险减仓事件／恢复时间；显式 Holm alpha／待接清单／CI入口。保留 R2 同单逐行一致测试。源与合成期望另行冻结至 R2 新文件／新结果目录；跨 Python 3.11／3.12／3.14 复现，完整 pytest 版本范围如实记录。
